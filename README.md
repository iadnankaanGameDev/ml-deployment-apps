# Machine Learning Deployment Apps

A curated collection of my machine learning app projects built with Python, scikit-learn, FastAPI, and Jupyter Notebook.

This repository works as an index for my deployed machine learning projects.  
Each project has its own separate repository with source code, model training notebooks, app files, and documentation.
